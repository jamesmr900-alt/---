# Maytoni · комплектатор (веб-сервис)

Пробная версия комплектатора с подключением к ИИ и отдельным инструментам.

Рабочий адрес — после развёртывания на Vercel (см. ниже): `https://<проект>.vercel.app/` и `/tools.html`.

Две страницы, работают по ссылке без регистрации:

| Страница | Что умеет | Нужна нейросеть |
|---|---|---|
| `index.html` — **Ассистент (ИИ)** | Диалог как с комплектатором: понимает план (PDF, фото) и КП (xlsx), подбирает освещение, считает освещённость, ищет аналоги, проверяет КП, собирает КП и отдаёт xlsx, по запросу строит интерактивную 3D-визуализацию помещения | Да, через прокси (ваш ключ Claude API) |
| `tools.html` — **Инструменты** | Каталог с фото; подбор «с нуля» по помещениям в трёх ценовых вариантах (с разбором экспликации из PDF/Excel); светорасчёт с картой в фиктивных цветах; комплекты — лента (лента, профиль, заглушки, крепления, рассеиватель, блок питания, управление), трековая система, DALI; аналоги по артикулу, описанию и из Excel/PDF; проверка КП по зонам и по правилам комплектации, сравнение двух КП; план помещения с подложкой, ручной расстановкой, размерами привязки, 3D и монтажной схемой PDF; КП в PDF с фото, отчёт Word, проект в файле | Нет, только алгоритмы в браузере |

КП общее для обеих страниц (хранится в браузере посетителя).

## Как устроено

```
Посетитель ──► Vercel / GitHub Pages (index.html, tools.html, каталог, расчёты в браузере)
                   │  только страница ассистента
                   ▼
            Прокси /api/chat (Vercel) или Cloudflare Worker — хранит ключ, инструкцию, лимиты
                   ▼
              Claude API (Anthropic)
```

Ключ API в браузер не попадает. Инструкция ассистента и список инструментов зашиты в прокси, поэтому прокси нельзя использовать для посторонних задач. Каталог, расчёты и КП работают в браузере: ассистент вызывает их как инструменты.

## Вариант без ключа API: артефакт Claude
Страница ассистента умеет работать внутри claude.ai как артефакт: запросы к Claude идут от аккаунта того, кто открыл страницу (тратится его лимит Claude), ключ API не нужен.
Опубликованная версия: https://claude.ai/artifact/ATQokKDLS4vbb8adutxULV (доступ выдаёт владелец кнопкой Share). Обновление артефакта: `./scripts/build_artifact.sh`, затем опубликовать папку `dist-artifact/`.
Инструкция ассистента и инструменты для этого режима — `js/agent-def.js`, генерируется из `worker/worker.js`: `node scripts/sync_agent_def.mjs`.

## Развёртывание на Vercel (вход через GitHub, ≈ 10 минут)
Vercel хранит сайт и прокси вместе: обе страницы и `/api/chat` на одном адресе.
1. Откройте vercel.com → **Sign Up** → **Continue with GitHub** (тот же аккаунт, что владеет репозиторием).
2. **Add New… → Project** → в списке репозиториев выберите `---` → **Import**.
3. На экране настройки: Framework Preset — **Other**, остальное не трогать. Раскройте **Environment Variables** и добавьте:
   - `ANTHROPIC_API_KEY` = ключ с console.anthropic.com (API Keys; на балансе должны быть средства).
   - по желанию: `MODEL` (`claude-sonnet-5-5` по умолчанию, `claude-opus-5-5` — точнее и дороже), `DAILY_LIMIT` (150), `ACCESS_CODE`.
4. **Deploy**. Через минуту появится адрес вида `https://имя-проекта.vercel.app`:
   - ассистент — `https://имя-проекта.vercel.app/`
   - инструменты — `https://имя-проекта.vercel.app/tools.html`
   - проверка прокси — `https://имя-проекта.vercel.app/api/health` (должно быть `"key":true`).
5. Дальше каждый коммит в `main` обновляет сайт автоматически. Ключ поменять: Settings → Environment Variables → Redeploy.

Важно: бесплатный тариф Vercel Hobby — для некоммерческого и тестового использования. Для рабочего сервиса компании нужен тариф Pro.

## Вариант: GitHub Pages (только «Инструменты»)
Settings → Pages → Source: *Deploy from a branch*, `main`, `/ (root)` → Save. Через пару минут: `https://jamesmr900-alt.github.io/---/tools.html`. Ассистент на этом адресе без нейросети.

## Вариант: прокси на Cloudflare Worker
Код `worker/worker.js` целиком вставляется в Cloudflare Worker (секрет `ANTHROPIC_API_KEY`, переменная `ALLOWED_ORIGINS`), адрес воркера — в `js/config.js`.

## Сколько стоит
GitHub Pages и Cloudflare Workers (до 100 000 запросов в сутки) — бесплатно. Платите только за Claude API по тарифу Anthropic: один диалог с проверкой КП — это несколько запросов к модели. Расходы ограничивают `DAILY_LIMIT` и лимит расходов в console.anthropic.com (Settings → Limits) — его стоит выставить обязательно.

## Обновление каталога и фото
Положите новые прайс-листы (`*Technical_2026_NEW.xlsx`, `*Maytoni_2026_NEW.xlsx`, `*Outdoor…`, `*Ledstrip…`, `*Lighting_control…`, `*Voltega…`) и `maytoni_catalog.xlsx` в одну папку и выполните:
```
pip install pandas openpyxl
python scripts/build_catalog.py <папка> data/catalog.json
```
Фото изделий (берутся из картинок внутри прайс-листов):
```
pip install pillow openpyxl
python scripts/build_photos.py <папка>
```
Затем `node scripts/mark_photos.mjs` (отмечает в каталоге позиции с фото) и `./scripts/stamp.sh` (сброс кэша браузеров). Закоммитьте `data/`.

## Подсказки
На каждой вкладке при первом открытии показывается карточка «для чего / что ввести / что получите / когда пользоваться» и пошаговый показ; при первом наведении на элементы всплывают подсказки. Кнопка «? Подсказки» в шапке показывает их заново. Тексты — `js/help-content.js`.

## Библиотека КСС (LDT / IES)
В библиотеке 1 425 светильников (папка «Data photometrica probanda», ноябрь 2026). Если для светильника есть файл КСС, светорасчёт берёт его реальную кривую силы света и поток (для светильников со встроенным LED — поток из файла; для светильников под лампу GU10 — форму кривой и КПД, снятые с лампой 38–40°).
- На странице «Светорасчёт» можно загрузить свои файлы .ldt / .ies или архив .zip — они запоминаются в браузере.
- Для всех пользователей: положите файлы в папку и выполните `node scripts/build_photometry.mjs <папка> --merge`, затем закоммитьте `data/photometry.json`. Артикул определяется по имени файла (например `DL048-01W.ldt`); файлы без артикула в имени перечисляются в `data/photometry_unmatched.txt`.

## Что считается и как
- Оценочный расчёт — метод коэффициента использования, как в калькуляторе maytoni-dsb.github.io/illuminance (те же типовые КСС и таблица kα, Z = 1,15). Коэффициент запаса 0,8, отражения 70/50/20.
- Карта в фиктивных цветах — точечный расчёт по той же КСС плюс отражённая составляющая, приведённый к средней освещённости оценки.
- Нормы — СП 52.13330.2016 (прил. Л), на уровне пола.
- В утопленные корпуса (Reif, Dot) и в Share/Flint подбираются только лампы 38–40° (3245, 3094, 3097) или модули до 60° (3121, 3123). При проверке КП количество не опускается ниже 70% от исходного.
- Можно загрузить свой файл КСС (.ldt) на странице «Инструменты».

Расчёт оценочный и не заменяет светотехнический проект (DIALux, Relux).
