По артикулу Maytoni

Порядок подбора: 1) тот же тип устройства — обязательно; 2) функции: протокол управления (DALI, TRIAC, Zigbee…), RGBW/RGB/MIX, цветовая температура, цоколь, напряжение; 3) цвет; 4) размеры. Если полного аналога нет — показываются ближайшие с отличиями.

По описанию или из файла (Excel, PDF)

Из PDF читается текстовый слой (сканы без текста не распознаются — для них используйте ассистента). Строки можно поправить перед подбором.

Замена для V2:

Для каждой зоны укажите размеры (или площадь). Норма подставляется по названию помещения (СП 52.13330), её можно поменять. Количество не опускается ниже 70% от исходного.

Документы и проект

Отчёт Word собирает всё, что сделано на странице: КП, проверку по зонам, замечания по правилам, светорасчёты с картами и планы расстановки. Проект — один файл со всеми данными: его можно открыть на другом устройстве или отправить коллеге.

Цены — РРЦ 2026 из прайс-листов Maytoni. Расчёт оценочный (метод коэффициента использования, СП 52.13330.2016), не заменяет светотехнический проект.
